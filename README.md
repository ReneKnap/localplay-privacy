# localplay-privacy

Public GitHub Pages site for the privacy policy of the **Localplay** Android app,
served at **https://reneknap.github.io/localplay-privacy/** and linked from the app's
Google Play listing.

`index.md` mirrors `PRIVACY.md` in the (private, local-only) app repository. When the
policy changes there, update it here as well — the effective date carries the change.
